# English Journey · 英语进阶

从零基础到大学/雅思的纯文字英语学习站，涵盖职场、日常生活、旅游等实用主题。

Live site: https://xiaochun4017.github.io/english-journey/

## 内容结构

- 🌱 零基础：字母、音标、打招呼、数字、颜色
- 🌿 初级：基础时态、疑问句、日常对话、必会动词
- 🌳 中级：进阶时态、从句、短语动词、连接词
- 🎓 大学/学术：Essay 结构、学术词汇、课堂用语、摘要写作
- 📝 雅思 IELTS：考试结构、四项策略、写作模板、口语题库、话题词汇
- 💼 职场：邮件、会议、面试、简历动词
- 🏘️ 日常生活：购物、点餐、看病、闲聊
- ✈️ 旅游：机场、酒店、问路、紧急情况
- 📚 词汇卡：100 张分类翻卡，进度本地保存
- ✏️ 自测：随机选择题，记录历史最佳
- 📅 每日打卡：连续天数、最近 7 天记录、累计天数
- 🌟 今日单词：按日期轮换，可手动换

## Desktop App

`~/Desktop/English Journey.app` — Chrome app 模式打开线上站，每次启动带时间戳参数强制加载最新版。
